# Project Base

Una base reutilizable para comenzar aplicaciones web, móviles, Android, de escritorio y backend sin partir de una carpeta vacía. No es solo documentación: incluye código inicial ejecutable, pruebas, contratos API, persistencia y herramientas de exportación. No crea tu producto completo automáticamente; prepara sus fundamentos para que tú, un equipo o un asistente de programación construyan las funciones particulares.

A reusable foundation for starting web, mobile, Android, desktop, and backend applications without beginning from an empty folder. It is not documentation alone: it includes executable starter code, tests, API contracts, persistence, and export tools. It does not automatically create your complete product; it prepares the foundations on which you, a team, or a coding assistant can build its specific features.
